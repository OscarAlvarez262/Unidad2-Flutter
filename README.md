# 📱 Prácticas Flutter - Unidad 2

Este repositorio reúne las prácticas y ejercicios realizados durante la segunda unidad de la materia **Desarrollo de Aplicaciones para Dispositivos Móviles**, utilizando **Flutter y Dart**.

## 🚀 Temáticas principales trabajadas

A lo largo de las prácticas se trabajaron diferentes elementos para continuar desarrollando aplicaciones móviles con Flutter:

* Uso de Flutter y Dart.
* Creación de interfaces gráficas.
* Organización de elementos mediante widgets.
* Manejo de diferentes tipos de widgets.
* Uso de `ListView`.
* Uso de `ListView.builder`.
* Creación de listas dinámicas.
* Manejo de índices de elementos.
* Uso de `onTap` para detectar interacciones.
* Uso de `SnackBar` para mostrar mensajes.
* Manejo de eventos dentro de las listas.
* Uso de `StatefulWidget` y `State`.
* Actualización de la interfaz mediante `setState()`.
* Uso de funciones para organizar el código.
* Manejo de información dentro de los widgets.
* Uso de parámetros para enviar información.
* Creación de interfaces interactivas.
* Organización del código de las aplicaciones.
* Desarrollo de diferentes pantallas y ejercicios prácticos.
* Implementación de diferentes funcionalidades mediante Flutter.

## 📚 Prácticas realizadas

Durante la unidad se desarrollaron diferentes ejercicios para poner en práctica los conceptos anteriores:

* **Práctica 7:** Desarrollo de una aplicación utilizando diferentes widgets y elementos de Flutter.
* **Práctica 8:** Trabajo con listas y organización de información dentro de la interfaz.
* **Práctica 9:** Uso de listas dinámicas mediante `ListView.builder` y manejo de elementos seleccionados.
* **Práctica 10:** Implementación de interacción con los elementos de una lista mediante eventos como `onTap` y uso de `SnackBar`.
* **Práctica Extra:** Ejercicio adicional para reforzar los conocimientos vistos durante la unidad.

## 📖 Manual del programador

El repositorio también incluye un **Manual del programador**, donde se documenta información relacionada con el desarrollo y funcionamiento de las aplicaciones realizadas durante la unidad.

## 🛠️ Requisitos

Para ejecutar las prácticas se necesita:

* Flutter SDK.
* Dart.
* Android Studio o un entorno compatible.
* Un dispositivo Android físico o un emulador.
* Un editor de código como Visual Studio Code o Android Studio.
